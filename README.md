# .github

Ce repo fournit les fichiers par défaut communs à tous les repos de l'organisation **sojadis-equipement** :

- Templates d'issues : [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE)
- Template de Pull Request : [`.github/pull_request_template.md`](.github/pull_request_template.md)
- Guide de workflow : [`docs/WORKFLOW.md`](docs/WORKFLOW.md)

Un repo de l'organisation qui n'a pas sa propre copie d'un de ces fichiers en hérite automatiquement (voir la [documentation GitHub sur les fichiers de communauté par défaut](https://docs.github.com/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file-for-your-organization)).
