# Comment contribuer

Conventions communes à tous les repos de l'organisation **sojadis-equipement**.

- Cycle de travail (issue → branche → Draft PR → review → merge), convention de nommage des branches et des commits, taille de PR indicative, note de conception optionnelle pour les changements complexes : voir [docs/WORKFLOW.md](docs/WORKFLOW.md).
- Les templates d'issues (Feature / Bug) et de Pull Request sont fournis automatiquement par ce repo à tous les repos de l'organisation qui n'ont pas leur propre copie.
